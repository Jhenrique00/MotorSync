# Checklist oficial da disciplina — NandoSync

**Fonte:** documento “Projeto de Conclusão — Desenvolvimento Mobile — 5º Período”, seções 2 e 3.

Os marcadores abaixo separam **conteúdo preparado** de **entrega efetiva**. Não se deve afirmar que o AVA foi enviado ou o aplicativo foi implementado sem evidência.

## Fase 1 — apresentações de 20 e 22 de outubro de 2026

Os slides do planejamento devem conter:

- [x] Título, conceito e propósito
- [x] Problema identificado
- [x] Solução proposta
- [x] Público-alvo
- [x] Objetivo geral
- [x] Objetivos específicos
- [x] Funcionalidades
- [x] Fluxo de navegação
- [x] Protótipos das principais telas
- [x] Tecnologias previstas, incluindo React Native
- [x] Tecnologia de persistência e diagrama entidade-relacionamento
- [x] Cronograma até a entrega final

A apresentação da Fase 1 contém esses **assuntos**; isso não equivale à confirmação de apresentação oral ou envio.

Entregáveis pelo AVA:

- [ ] Enviar PDF da apresentação
- [ ] Enviar **link do GitHub Projects** (não apenas do repositório)
- [ ] Conferir se GitHub Project está associado ao repositório e se as Issues foram adicionadas ao quadro

Acompanhamento recomendado:

- [x] Criar repositório
- [x] Criar Issues para planejar o desenvolvimento
- [ ] Conferir/organizar status **A Fazer, Em Desenvolvimento, Em Teste, Concluído** no **GitHub Projects**
- [ ] Atualizar status conforme o trabalho avança

## Fase 2 — apresentações de 24 e 26 de novembro de 2026

Requisitos mínimos do aplicativo:

- [ ] React Native
- [ ] Navegação entre múltiplas telas
- [ ] Interface apropriada para dispositivos móveis
- [ ] Persistência real de dados
- [ ] Cadastro de usuário e login (**não contam como CRUD**)
- [ ] Pelo menos uma entidade com **criar, consultar, editar e excluir** (CRUD)
- [ ] Validação básica de formulários
- [ ] Tratamento básico de erros
- [ ] Demonstração de um fluxo completo no dispositivo ou emulador

Demonstração sugerida pelo professor: abrir → login → inserir → consultar → alterar → excluir/concluir → verificar persistência.

Entregáveis:

- [ ] Aplicativo funcionando para demonstrar
- [ ] Código-fonte React Native no GitHub
- [ ] README na **raiz do código-fonte**, com tecnologias, modelo lógico e instruções de configuração/execução
- [ ] Vídeo demonstrativo com duração **máxima de 10 minutos** no Google Drive
- [ ] Enviar no AVA os links do repositório e do vídeo compartilhado

## Observação de escopo

O documento exige **ao menos um CRUD completo**, não CRUD completo de todas as telas. Propomos focar primeiro o CRUD de veículos. Recursos gerenciais, relatórios detalhados e financiamentos completos só contam como entregues quando estiverem funcionando.

**Não confundir o limite de 15 minutos para a apresentação oral combinado pela equipe com o limite oficial do vídeo da Fase 2, que é de 10 minutos.**
